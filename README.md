# Study Tracker

Консольный трекер учёбы на Python. Записывает, сколько минут и чем ты занимался каждый день.

## Что умеет
- Добавить запись за сегодня (минуты и описание). Если записей за день несколько, минуты суммируются, а описания склеиваются
- Показать историю по дням
- Проверять ввод: вместо числа минут буквы не ломают программу

## Как запустить
1. Установить Python 3
2. Скачать `tracker.py`
3. В папке с файлом выполнить: `python tracker.py`

Файл `log.json` с данными создаётся автоматически при первой записи.
